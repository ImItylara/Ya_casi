Proyecto: Sorpresa de viaje

Abre index.html en el navegador.

Para mostrar la captura real automáticamente al revelar la tarjeta:
1. Guarda la imagen en esta carpeta.
2. Ponle el nombre captura-vuelo.png.

También puedes elegir una imagen desde el botón “Agregar captura real de la reserva”. Esa selección se muestra en la página actual. Para que aparezca al volver a abrir el archivo, guarda una copia en esta carpeta con el nombre captura-vuelo.png.
